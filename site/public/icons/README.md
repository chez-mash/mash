# Interface icons

Phosphor icons (https://phosphoricons.com, MIT licence), bold weight, drawn by
the stylesheets as CSS masks where an icon has no element of its own:
`download.svg` before a release file in a table, and `search.svg` in the
button that opens search. The components draw the same set inline through
`src/components/LineIcon.astro`, from `src/icons.ts`.
