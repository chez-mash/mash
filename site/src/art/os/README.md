# Operating system marks

Copies of the dashboard's marks (`dashboard/public/os/`), drawn beside a
system's name on the site: the download buttons and the
code windows. `src/art/os/` holds the same files for inlining.

- `apple.svg`, `linux.svg`: Simple Icons `16.36.0`, CC0. Source:
  `https://cdn.jsdelivr.net/npm/simple-icons@16.36.0/icons/NAME.svg`.
- `windows.svg`: a plain four-pane glyph drawn for Mash. Simple Icons carries
  no Windows mark.

`../raycast.svg`, the mark on the landing page's Raycast button, is from the
same Simple Icons release under the same license.

The license text is included alongside the assets. Marks remain the property
of their respective owners.
