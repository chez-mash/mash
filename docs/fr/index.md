# Mash en français

Retrouvez des décisions et des solutions dans les conversations que Claude
Code, Codex, GitHub Copilot, Cursor, OpenCode et Antigravity ont déjà
enregistrées. Ouvrez le message d’origine pour lire ce qui a motivé une
décision.

Mash est un logiciel libre qui s’exécute sur votre ordinateur. Par défaut,
l’indexation et la recherche restent locales et aucun compte Mash n’est
nécessaire.
