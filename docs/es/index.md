# Mash en español

Mash te ayuda a encontrar decisiones y soluciones en tus conversaciones con
Claude Code, Codex, GitHub Copilot, Cursor, OpenCode y Antigravity. Puedes
abrir el mensaje original para ver cómo se llegó a una decisión.

Mash es de código abierto. Con la configuración predeterminada, el índice y
las búsquedas se ejecutan en tu equipo y no necesitas una cuenta de Mash.
