# Mash 日本語ガイド

Mash は、Claude Code、Codex、GitHub Copilot、Cursor、OpenCode、Antigravity
などのコーディングエージェントがすでに保存したチャットを検索します。
検索結果から元のメッセージを開き、判断の経緯を読み返せます。

ブラウザーや端末から自分で検索できます。エージェントを接続すると、
過去の作業を代わりに探してもらうこともできます。Mash はオープンソースで、
既定ではインデックス作成と検索をお使いのコンピューターで行います。Mash のアカウントは不要です。
