# 履歴とプライバシー

<span id="what-stays-on-your-machine"></span>

## 自分のコンピューターに残るデータ

既定の設定では、インデックスの作成も検索も、このコンピューターの中で行います。
エージェントの元の履歴ファイルは変更されません。Mash のアカウントも不要です。
Mash は読み込んだチャットのコピーを保存します。コピーには機密情報が含まれることがあります。
[公開デモ](https://getmash.io/demo/)ではサンプルのチャットを使います。お使いのコンピューターの履歴にはアクセスできません。

既定のダッシュボードと検索サービスは、同じコンピューター上のプログラムからログインなしで利用できます。
そのコンピューターを利用する人を信頼できる環境で、既定の設定を使ってください。
別の端末から開くには、[サインイン付きのダッシュボード](dashboard.md#open-it-from-your-phone-or-another-computer)を使います。

OpenCode など、履歴を SQLite に保存するエージェントでは、Mash が読み取るときに
隣に `-wal` や `-shm` ファイルが作られる場合があります。これは SQLite の動作で、データベースの内容は変更されません。

<span id="choose-agent-access"></span>

## エージェントがアクセスできる内容を選ぶ

エージェントを接続しなくても、ローカルのダッシュボードや端末からチャットを検索できます。
Mash に読み込ませる履歴と、Mash に接続するエージェントは別々に選びます。

- **セットアップ時**は、すべてのエージェントの選択を外すと、新しい接続を省けます。
  すでに入っているツールやプラグインはそのままです。
  [エージェントを接続せずにセットアップする](installation.md#skip-agent-connections)。
- **既存の連携を解除する**には、Mash のツールを外し、プラグインを無効にするか
  削除してから、エージェントを再起動します。プラグインを個別に入れた場合も同じです。
  [エージェントとの接続を解除する](agents.md#disconnect-an-agent)。
- **特定の履歴のインデックス更新を止める**には、**settings** の **agent histories** で
  対象をオフにし、設定を保存します。更新を監視するプロセスが起動していれば、再起動します。
  既存の接続はそのままで、登録済みのチャットは引き続き検索できます。
  [Mash からチャットを削除する](#remove-a-chat)。

セットアップでエージェントを接続すると、Mash はツールを登録し、プラグインのインストールを試みます。
[接続時にインストールされるもの](agents.md#what-the-connection-installs)。

<span id="when-history-can-leave-your-machine"></span>

## 履歴が外部に送られる場合

| Mash の使い方 | 読み込まれる内容や送られる内容 |
| --- | --- |
| ローカルのダッシュボードや端末から検索 | Mash はこのコンピューターのインデックスを検索して結果を表示します。 |
| エージェントに接続したツール（MCP） | エージェントは登録済みのチャットを検索し、一致したメッセージとその前後を読めます。読み込んだ内容はモデルの提供元に送られる場合があります。 |
| フックを有効にした Mash プラグイン | セッションの開始時に、プラグインが直近のチャットの情報や保存済みの記憶をエージェントに渡すことがあります。関連ファイルを読み込んだときに、チャットの抜粋を渡すこともあります。MCP 接続がなくても、こうした情報がモデルの提供元に送られる場合があります。[自動処理の内容と止め方（英語）](../plugin.md#what-happens-without-asking)。 |
| 複数のコンピューターで共有 | インデックスに登録されたチャットと保存済みの添付ファイルが、自分で設定したサーバーに送られます。同じグループのトークンを持つコンピューターから読めます。今後の送信を止めるには、**settings** の **index into** で **this machine only** を選んで保存します。更新を監視するプロセスが起動していれば、再起動します。送信済みのコピーはサーバーに残ります。[共有前に確認すること（英語）](../shared-index.md#before-sharing)。 |
| ダッシュボードの Mashy | 有効にすると、Mashy は質問、選択した文章、回答のために確認したチャットのテキストや記憶を[自分で設定したモデルサービス（英語）](../configuration.md#the-dashboard-assistant)に送ります。送信を止めるには **settings** で **Mashy** をオフにして保存するか、設定ファイルの `[assistant]` セクションを削除します。 |

- **リモートの埋め込み処理**には、機密情報を含む可能性のある検索用テキストが送られます。
  既定ではローカルで処理し、検索クエリの埋め込みは常にローカルで計算します。
  [埋め込み処理（英語）](../configuration.md#embedding-inference)。
- **リモートで検索結果を並べ替える機能**には、クエリと対象の抜粋が送られます。
  既定ではローカルで処理します。[リモート再ランキング（英語）](../configuration.md#remote-reranking)。
- **過去のチャットから記憶を作る場合**は、選んだチャットが、サインイン済みのエージェントの提供元に送られます。
  Mash はセットアップ時に実行してよいか確認します。
  [過去のチャットから記憶を作る仕組み（英語）](../records.md#backfill-earlier-memory)。

<span id="where-mash-stores-data"></span>

## Mash のデータ保存場所

既定では、読み込んだチャットは `~/.mash/mash.sqlite3`、設定は `~/.mash/config.toml` に保存されます。
Windows の `~` はユーザープロファイルです。
検索に使うチャットのテキストなどは、検索サービスの Qdrant にも保存されます。
Windows では通常、システムドライブ上の `C:\mash-qdrant\storage` に保存されます。
[OS ごとの検索サービスの保存先](local-search.md#where-qdrant-stores-data)

`mash status` の `database_path` でデータベースを、Mash が Qdrant をインストールした場合は
`local_qdrant.installed.storage` で検索データの保存先を確認できます。
`mash uninstall` は、Windows の Qdrant 用フォルダーを含め、削除予定の項目を表示します。
削除を実行するときは `--yes` を付けてください。[削除される項目（英語）](../uninstall.md)

<span id="try-a-small-local-setup"></span>

## 1 つの履歴で試す

まずは [デモでサンプルチャットを検索](https://getmash.io/demo/#/search?q=invoice+exports+queue)できます。
自分の履歴を 1 つだけ読み込むには、初回セットアップで次のように選びます。

1. [クイックスタートのインストーラー](quick-start.md#install-it-yourself)を実行します。
   表示されたアドレスをブラウザーで開き、端末は開いたままにします。
2. 最初に確認画面が表示された場合は、**Customize setup** を選びます。
   過去 1 週間に使ったエージェントを 1 つ選び、その履歴だけを残して **Next** を押します。
3. **another number of days** を選んで **7** と入力し、過去 7 日間に更新された履歴を選びます。Mash は会話に記録された活動時刻を使い、記録がない場合は履歴ファイルの最終更新日時を使います。対象の会話には、それより古いメッセージが含まれることがあります。
   **Next** を押し、エージェントの選択をすべて外して確認画面に進みます。
4. **this machine only** と **no agents** が表示されていることを確認します。
   **Set up and index** を選びます。読み込みが終わったら **chats** を開き、そのチャットで使った言葉を検索します。

あとから期間を広げたり、エージェントを接続したりできます。
[ダッシュボードでのセットアップ](dashboard.md#set-up-mash-from-the-dashboard)

試用を終えるときは `mash uninstall` で削除内容を確認できます。
実行すると Mash のインデックスとサービスが削除され、エージェントの元のチャットは残ります。
[削除される項目（英語）](../uninstall.md)

<span id="shorten-the-history-range"></span>

## 読み込む履歴の期間を短くする

ダッシュボードの **settings** を開きます。
**history range** で **recent updates**（以前のバージョンでは **recent only**）を選び、日数を入力します。
**Review changes**、**Save to file** の順に選びます。
新しい期間で読み込むには `mash index` を実行します。履歴更新の監視プロセスが動いていれば、
再起動して保存済みの設定を読み込ませることもできます。

期間の変更は、以降のインデックス作成に適用されます。たとえば 90 日から 7 日に短くしても、
最終更新が 30 日前のチャットをすでにインデックスに登録していれば、インデックスを再度更新したあとも検索できます。
最近更新されたチャットに、それより古いメッセージが含まれることもあります。
特定のチャットを Mash から消すには、[チャットを削除する手順](#remove-a-chat)をご覧ください。

<span id="sensitive-information"></span>

## 機密情報

既定では、検索結果や共有先に送る履歴のうち、検出できる認証情報はマスクされます。
すべてを検出できるわけではないため、共有する内容は事前に確認してください。
ローカルの履歴やバックアップには認証情報が含まれる場合があります。元のチャットと同じように管理してください。

1 つのメッセージ内で `<private>…</private>` に囲まれたテキストは、Mash の保存するメッセージ本文から省かれます。
開始タグと終了タグが必要です。エージェントの元ファイルと添付ファイルの内容はそのままです。

<span id="remove-a-chat"></span>

## チャットを削除する

`mash list-chats` または `mash search` で `chat_id` を調べてから実行します。

```sh
mash forget CHAT_ID
```

Mash はローカルに保存したチャットのコピーと、そのチャットを引用したことのある記憶を削除します。
同じチャットは再び読み込まれません。共有が有効なら、共有先にも削除を反映しようとします。
コマンドの結果で未完了の処理がないか確認してください。

エージェントの元ファイル、以前のバックアップ、別のコンピューターで個別に読み込んだコピーは残ります。
削除は元に戻せません。あとで必要になる場合は、先に [バックアップ（英語）](../backup.md#make-a-portable-backup)を作成してください。
