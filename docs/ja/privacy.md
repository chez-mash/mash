# 履歴とプライバシー

<span id="what-stays-on-your-machine"></span>

## 自分のコンピューターに残るデータ

既定の設定では、インデックスの作成も検索も、このコンピューターの中で行います。
エージェントの元の履歴ファイルは変更されません。Mash のアカウントも不要です。
Mash は読み込んだチャットのコピーを保存します。コピーには機密情報が含まれることがあります。
[公開デモ](https://getmash.io/demo/)ではサンプルのチャットを使います。お使いのコンピューターの履歴にはアクセスできません。

既定のダッシュボードと検索サービスは、同じコンピューター上のプログラムからログインなしで利用できます。
そのコンピューターを利用する人を信頼できる環境で、既定の設定を使ってください。
別の端末から開くには、[サインイン付きのダッシュボード](dashboard.md#open-it-from-your-phone-or-another-computer)を使います。

OpenCode など、履歴を SQLite に保存するエージェントでは、Mash が読み取るときに
隣に `-wal` や `-shm` ファイルが作られる場合があります。これは SQLite の動作で、データベースの内容は変更されません。

<span id="where-mash-stores-data"></span>

## Mash のデータ保存場所

既定では、読み込んだチャットは `~/.mash/mash.sqlite3`、設定は `~/.mash/config.toml` に保存されます。
Windows の `~` はユーザープロファイルです。
検索に使うチャットのテキストなどは、検索サービスの Qdrant にも保存されます。
Windows では通常、システムドライブ上の `C:\mash-qdrant\storage` に保存されます。
[OS ごとの検索サービスの保存先（英語）](../local-search.md#where-qdrant-stores-data)

`mash status` の `database_path` でデータベースを、Mash が Qdrant をインストールした場合は
`local_qdrant.installed.storage` で検索データの保存先を確認できます。
`mash uninstall` は、Windows の Qdrant 用フォルダーを含め、削除予定の項目を表示します。
削除を実行するときは `--yes` を付けてください。[削除される項目（英語）](../uninstall.md)

<span id="when-history-can-leave-your-machine"></span>

## 履歴が外部に送られる場合

- **エージェントを接続する。** 接続したエージェントは検索結果や抜粋を取得できます。
  取得したテキストはエージェントのコンテキストに入り、モデルの提供元に送られる場合があります。
  [プラグインのフック（英語）](../plugin.md#what-happens-without-asking)も、MCP 接続とは別に抜粋を渡すことがあります。
  ダッシュボードや端末だけで検索するには、エージェントを接続せず、インストール済みの Mash プラグインも無効にするか削除します。
- **複数のコンピューターで共有する。** 保存されたチャットと添付ファイルが、自分で設定した Mash サーバーに送られます。
  そのグループのトークンを持つコンピューターから読めます。[共有前に確認すること（英語）](../shared-index.md#before-sharing)
- **リモートの埋め込み処理を使う。** 検索用に整えたテキストが処理先に送られます。
  その中には機密情報が含まれる場合があります。既定ではローカルで処理し、検索語の埋め込みは常にローカルで計算します。
- **リモートで検索結果を並べ替える。** 検索語と並べ替えの対象となる抜粋が処理先に送られます。
  この処理は、自分でリモートを設定するまではローカルで行います。
- **ダッシュボードのアシスタントを使う。** 質問と、回答に使うチャットのテキストや記憶が、
  [自分で設定したモデルサービス（英語）](../configuration.md#the-dashboard-assistant)に送られます。設定するとアシスタントが有効になります。
- **過去のチャットから記憶を作る。** 選んだチャットが、サインイン済みのエージェントの提供元に送られます。
  Mash はセットアップ時に実行してよいか確認します。[過去のチャットから記憶を作る仕組み（英語）](../records.md#backfill-earlier-memory)

<span id="try-a-small-local-setup"></span>

## 1 つの履歴で試す

まずは [デモでサンプルチャットを検索](https://getmash.io/demo/#/search?q=invoice+exports+queue)できます。
自分の履歴を 1 つだけ読み込むには、初回セットアップで次のように選びます。

1. [クイックスタートのインストーラー](quick-start.md#install-it-yourself)を実行します。
   表示されたアドレスをブラウザーで開き、端末は開いたままにします。
2. 最初に確認画面が表示された場合は、**Customize setup** を選びます。
   過去 1 週間に使ったエージェントを 1 つ選び、その履歴だけを残して **Next** を押します。
3. **another number of days** を選んで **7** と入力し、過去 7 日間に更新された履歴を選びます。Mash は会話に記録された活動時刻を使い、記録がない場合は履歴ファイルの最終更新日時を使います。対象の会話には、それより古いメッセージが含まれることがあります。
   **Next** を押し、エージェントの選択をすべて外して確認画面に進みます。
4. **this machine only** と **no agents** が表示されていることを確認します。
   **Set up and index** を選びます。読み込みが終わったら **chats** を開き、そのチャットで使った言葉を検索します。

あとから期間を広げたり、エージェントを接続したりできます。
[ダッシュボードでのセットアップ](dashboard.md#set-up-mash-from-the-dashboard)

試用を終えるときは `mash uninstall` で削除内容を確認できます。
実行すると Mash のインデックスとサービスが削除され、エージェントの元のチャットは残ります。
[削除される項目（英語）](../uninstall.md)

<span id="sensitive-information"></span>

## 機密情報

既定では、検索結果や共有先に送る履歴のうち、検出できる認証情報はマスクされます。
すべてを検出できるわけではないため、共有する内容は事前に確認してください。
ローカルの履歴やバックアップには認証情報が含まれる場合があります。元のチャットと同じように管理してください。

1 つのメッセージ内で `<private>…</private>` に囲まれたテキストは、Mash の保存するメッセージ本文から省かれます。
開始タグと終了タグが必要です。エージェントの元ファイルと添付ファイルの内容はそのままです。

<span id="remove-a-chat"></span>

## チャットを削除する

`mash list-chats` または `mash search` で `chat_id` を調べてから実行します。

```sh
mash forget CHAT_ID
```

Mash はローカルのコピーを削除し、同じチャットを再び読み込まないようにします。
共有が有効なら、共有先にも削除を反映しようとします。コマンドの結果で未完了の処理がないか確認してください。

エージェントの元ファイル、以前のバックアップ、別のコンピューターで個別に読み込んだコピーは残ります。
削除は元に戻せません。あとで必要になる場合は、先に [バックアップ（英語）](../backup.md#make-a-portable-backup)を作成してください。
