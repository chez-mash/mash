# チャットの履歴を最新に保つ

エージェントが保存した履歴を Mash が読み込むと、新しいチャットを検索できるようになります。
直前のチャットを探しているなら、[今すぐ履歴を更新](#refresh-now)してください。
作業中も更新を続けるには、[履歴の変更を監視](#keep-refreshing-while-you-work)します。

<span id="refresh-now"></span>

## 今すぐ履歴を更新する

エージェントがチャットを保存したコンピューターで、次のコマンドを実行します。
Mash が読み込む履歴をまだ選んでいなければ、先に[セットアップを完了](installation.md#connect-your-histories)してください。

```bash
mash index
mash status
```

`mash index` は新規または更新された履歴を読み込み、進捗を表示します。
最後の結果で、読み込みが完了していない履歴や、共有先への送信が保留中の履歴がないか確認してください。
未完了の処理があれば、表示された理由に対応してから `mash index` をもう一度実行します。
`mash status` では、このコンピューターで検索する準備ができているかを確認できます。

履歴の読み込みが終わると、ダッシュボードのチャット一覧が更新されます。
表示中の検索結果を更新するには **Search again** を選びます。
**Search again** が表示されない場合は、ページを再読み込みすると同じ検索を実行できます。

<span id="keep-refreshing-while-you-work"></span>

## 作業中も履歴を更新する

別のターミナルウィンドウで次のコマンドを実行し、起動したままにします。

```bash
mash index --watch
```

最初に履歴を 1 回読み込み、その後は履歴の変更が落ち着いてから更新します。
更新処理の間隔は 30 秒以上です。前の更新に時間がかかった場合は、次の更新までさらに待つこともあります。
Ctrl-C を押すと、実行中の更新を終えてから監視を停止します。端末を閉じても停止します。

設定で選んだエージェント、履歴をさかのぼる期間、このコンピューターだけで使うか共有するかの指定が適用されます。
作業中の更新に古い履歴も含める場合は、次のコマンドを使います。

```bash
mash index --watch --all-history
```

履歴をさかのぼる既定の期間を変えるには、[設定ファイル（英語）](../configuration.md)を編集してください。
`--watch` は `--full` や `--reread` と併用できません。

Mash をアップグレードすると、監視プロセスは実行中の更新を終えてから、同じオプションで新しい `mash` を起動します。
端末やサービスを再起動せずに監視が続きます。
新しい実行ファイルを起動できない場合は、エラーを表示して終了するので、自分で起動し直してください。

<span id="what-the-agent-plugin-does-automatically"></span>

## エージェントのプラグインによる自動更新

[Mash プラグイン（英語）](../plugin.md)はセッションの開始時に、未反映の履歴を低い優先度で読み込みます。実行頻度は 10 分に 1 回までです。
エージェントはこの処理の完了を待ちません。すでに別の読み込み処理が動いている場合は、何も変更せずに終了します。

プラグインのフックが履歴を読み込むのはセッションの開始時です。
長く開いているセッションの途中でも更新したい場合は、監視を使います。
開始時の自動更新を無効にするには、エージェントの環境で `MASH_AUTO_INDEX=off` を設定してください。

<span id="understand-freshness-warnings"></span>

## 履歴の更新に関する警告が出たら

`mash init` や 1 回だけの `mash index` を実行したあとは、手動で更新できます。
検索の対象は、最後に履歴を読み込んだ時点の内容です。
古いバージョンで「Live indexing is inactive」と表示される場合は、次に履歴を読み込むときに更新されるという意味です。

前回の読み込みが途中で終わった場合や、Mash が読み込み状況を確認できなかった場合も、以前のチャットが検索結果に出ることがあります。
警告に従ってインデックスを確認するか、履歴を更新してください。
最近のチャットが見つからなければ、`mash index` を実行してからもう一度検索します。

- 継続して更新したい場合は監視を起動したままにします。監視が動いていても、すべての履歴を正常に読み込めたとは限りません。
- アップグレード直後の警告や、インデックスに互換性がないという警告が出た場合は、再試行の前に[アップグレードガイド（英語）](../upgrades.md)をご覧ください。

<span id="in-the-dashboard"></span>

## ダッシュボードで更新を確認する

履歴を読み込むと、新しいチャットやメッセージがダッシュボードに反映されます。
開いているチャットで一番下までスクロールしていれば、新しいメッセージが自動で表示されます。
途中を読んでいる場合は **N new messages** を選ぶと新着分を読めます。
すでに表示されているメッセージは、**Show updated messages** を選ぶまでそのままです。
[ダッシュボードの更新の仕組み](dashboard.md#keep-your-place)

<span id="across-machines"></span>

## 別のコンピューターの履歴が見つからないとき

別のコンピューターのチャットが見つからなければ、まずそのコンピューターを確認します。
チャットの読み込みと共有先への送信は、元のコンピューターで行われます。
そこで `mash status --shared` を実行し、送信状況を確認してください。
送信が保留中なら、接続を復旧してから同じコンピューターで `mash index` をもう一度実行します。

[複数のコンピューターで履歴を共有する設定（英語）](../shared-index.md)をご覧ください。
