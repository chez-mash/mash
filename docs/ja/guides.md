# Mash ドキュメント

Mash は、コーディングエージェントとの過去の会話を探すツールです。
初めて使う場合は [クイックスタート](quick-start.md) から始めてください。
日本語訳があるガイドへのリンクを掲載しています。「英語」とあるリンクは英語のガイドを開きます。
