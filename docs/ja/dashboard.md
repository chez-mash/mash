# Mash のダッシュボードを使う

[日本語のサンプルチャットをデモで検索](https://getmash.io/demo/#/search?q=%E8%AA%8D%E8%A8%BC%E3%83%88%E3%83%BC%E3%82%AF%E3%83%B3%E3%81%AE%E6%9B%B4%E6%96%B0%E6%89%8B%E9%A0%86%E3%82%92%E8%A6%8B%E7%9B%B4%E3%81%97%E3%81%9F)し、結果を開いて元の会話を読んでみてください。
[保存された決定事項のサンプル](https://getmash.io/demo/#/record/record-sign-in-tokens?node=laptop)では、**open the message** を選ぶと、根拠になったメッセージが表示されます。
デモの検索では、サンプルチャットに出てくる単語やフレーズを使えます。

配布版の Mash にはダッシュボードが含まれています。ソースから作る場合は
[ダッシュボードを含めてビルド（英語）](../install-methods.md#include-the-web-dashboard)します。
[Mash をインストール](quick-start.md#install-it-yourself)したら、端末で次のコマンドを実行してください。

```sh
mash dash
```

表示されたアドレス（通常は [http://127.0.0.1:8790](http://127.0.0.1:8790)）をブラウザーで開きます。
セットアップ済みなら、**overview** に最近のチャットや記憶が表示されます。
使っている間は端末を開いたままにしてください。Ctrl-C でダッシュボードを終了できます。
ページを開けない場合は [起動時の確認手順](troubleshooting.md#the-dashboard-doesnt-open)をご覧ください。

起動時の出力が JSON 形式の場合、アドレスは `dashboard` フィールドにあります。
標準エラー出力をファイルやパイプにリダイレクトした場合や、古いリリースの端末出力でこの形式が使われます。
[プラグイン（英語）](../plugin.md)を入れている場合は、Claude Code の `/mash:dashboard` を使うか、エージェントにダッシュボードを開くように頼めます。

ダッシュボードのボタンやメニューは英語で表示されます。既定のローカルダッシュボードにサインインは不要です。
接続を受け付けるアドレスを変更する前に、[アクセスを制限する](#keep-access-private)方法をご確認ください。

<span id="set-up-mash-from-the-dashboard"></span>

## ブラウザーでセットアップする

初回の設定はブラウザーから行えます。`mash dash` を実行し、表示されたアドレスを開いてください。
設定ファイルがない場合、メニューや検索のないセットアップ画面が開きます。**Skip to the dashboard** で先にダッシュボードを見ることもできます。
あとから **settings** に戻れば、[履歴を読み込み直さずにエージェントを接続](agents.md#connect-claude-code-codex-or-copilot)できます。

見つかった履歴、読み込む期間、接続できるエージェントを確認します。**Show history folders** で保存場所を確認できます。
既定では、このコンピューターで過去 90 日間に更新された履歴ファイルやセッションを読み込みます。
それより前のメッセージが含まれることもあります。
設定を使うなら **Set up and index**、履歴や期間などを変えるなら **Customize setup** を選びます。

- ダッシュボードで自分で検索するなら、**connect Mash to** に **no agents** と表示されていることを確認します。
- エージェントに検索してもらうなら、**Choose agents to connect** を開くか、**Customize setup** 内のエージェントの画面で接続先を選びます。
- 最初からエージェントが選択されているバージョンでは、**Skip agent connections** を選ぶか、エージェントの画面で選択を外せます。
  最初に履歴の選択画面が開いた場合は、**Next** でエージェントや確認の画面に進みます。

確認画面の **Set up and index** または **Set up without indexing** を選ぶと、内容が反映されます。
Mash は設定ファイルを書き、選んだエージェントの CLI を使って接続します。履歴の読み込みを選んだ場合は、バックグラウンドで開始します。
画面には作成した設定、エージェントの CLI が変更したファイル、接続を元に戻すコマンドが表示されます。
最初の読み込み中はチャットが表示されるまで進み具合を確認できます。

- 読み込みには検索サービスが必要です。停止中の場合は、インストール時に選んだ方法で起動してください。
  接続エラーが出る場合は理由を確認し、[検索サービスを修復](troubleshooting.md#qdrant-connection-failed)してから **Check search service again** を選びます。
  **Set up without indexing** で設定だけを先に保存できます。接続を確認できたら、保存後の画面にチャットを読み込むコマンドが表示されます。
- 意味で検索するには、[モデルを用意して検索データを作成（英語）](../indexing.md#enable-semantic-search)し、[検索モードを切り替えます](#choose-a-search-mode)。
- セットアップ済みのコンピューターでやり直すと、設定が書き換わり、以前のファイルが同じフォルダーに残ります。
- 別のコンピューターとの共有、過去のチャットからの記憶作成、別の場所に保存された履歴の追加には、`mash init` または設定ファイルを使います。
- 別のコンピューターからアクセスできるダッシュボードでセットアップや設定変更を行うには、サービス設定を指定して起動する必要があります。

<span id="the-rail"></span>

## メニューから目的のページを開く

画面左側のメニューからページを移動できます。スマートフォンではメニューボタンを押して表示します。

- **overview** は最近のチャットと記憶、コンピューターやエージェントごとのチャット件数を表示します。
- **chats** には新しい順にチャットが並び、検索欄もあります。**viewing history** を開くと、同じブラウザーセッション内で見たチャットを前回の位置から読めます。
- **agents**、**machines**、**projects** では、選んだエージェント、コンピューター、プロジェクトの最近のチャットや内訳を確認できます。
- **memory** では、保存された決定事項、好み、事実を確認できます。
- **services** と **fleet manager** では、プロセスやデータベースの状態、接続済みのエージェントなどを確認できます。
  **fleet manager** は複数のコンピューターを管理する設定をしている場合に表示されます。[サービスの管理（英語）](../services.md)
- **tool explorer** には、エージェントが使える Mash のツールと引数が並びます。
  読み取り専用のツールを実行し、エージェントが受け取る応答を確認できます。
- **settings** では、設定とインデックスの状態を確認できます。
  読み込むエージェントや、履歴の更新日をどこまでさかのぼるか、共有の有無、記憶の作成、認証情報のマスクを変更できます。
  [Mashy](#ask-mashy) を設定済みなら、有効・無効の切り替えやモデルの選択もできます。
  保存前のファイルは `config.toml.previous` に残ります。履歴更新の監視プロセスを再起動し、エージェントも接続し直して変更を反映してください。Mashy の設定はすぐに反映されます。
  検索や保存先の詳細設定は閲覧専用です。ほかのコンピューターからアクセスできる場合は、`--services-config` を指定して起動したときだけ設定を変更できます。

右上のボタンで明るい表示と暗い表示を切り替えられます。選択はブラウザーに記憶されます。

<span id="check-if-local-search-is-ready"></span>

### ローカル検索の状態を確認する

**settings** の上部に検索の状態が表示されます。**storage** の件数は、Mash が保存した履歴の数です。
検索するには検索サービスが起動し、検索用のインデックスが最新である必要があります。

ローカル検索サービスを使えない場合は、もう一度読み込む前に [接続できない理由を確認](troubleshooting.md#qdrant-connection-failed)してください。
単語検索にはモデルは不要です。[意味で検索する（英語）](../indexing.md#enable-semantic-search)場合にモデルをインストールします。

<span id="find-and-read-a-chat"></span>

## チャットを探して読む

**chats** を開き、**Search your history** に覚えている言葉を入力して Enter を押します。
結果を開くと、元のチャットの該当メッセージに移動します。検索語を入力する前はチャットの一覧が表示されます。
エージェント、コンピューター、プロジェクト、日付で検索結果や一覧を絞り込めます。
変更した項目は **Apply filters** を選ぶまで点線の枠で表示され、その後、検索欄のタグになります。タグを選ぶと、その条件を外せます。

結果が空なら **Clear filters** で条件を外し、同じ言葉をすべてのチャットから検索できます。一覧に戻るバージョンでは検索語を送信し直してください。
**Browse chats** は現在の条件でチャットの一覧を開きます。ブラウザーの戻るボタンで検索に戻れます。
[新しいチャットを読み込んだあと](troubleshooting.md#new-chats-are-missing-or-search-is-behind)は、**Search again** を押します。
チャットが一覧にある場合は [検索語と検索モードを確認](troubleshooting.md#search-returns-no-results)してください。

会話では自分のメッセージが右側に、エージェントの応答が左側に並びます。
ツールの呼び出しや推論は 1 行にまとめられていて、開くと各操作や出力を確認できます。
サイドパネルには、そのページの自分の指示、同じプロジェクト内のチャット、この会話から保存された記憶が表示されます。
**Copy session ID** を使って [元のセッションを再開（英語）](../pick-up-work.md#reopen-the-original-session)したり、
[新しいセッションに作業を引き継いだり（英語）](../pick-up-work.md#ask-an-agent-for-a-recap)できます。
チャットや記憶の表示ページは読み取り専用です。

<span id="choose-a-search-mode"></span>

### 検索モードを選ぶ

検索後、絞り込み項目の横にある **search: default** を探してください。結果が表示されると、
**default (words)** または **default (meaning)** が表示されます。
メニューで **words** または **meaning** を選び、**Apply filters** で検索し直します。

**words** はチャットに含まれる語句を検索します。**meaning** は [オプションのモデル（英語）](../indexing.md#enable-semantic-search)で意味を検索します。英語で質問してください。
選んだモードは同じ検索の結果をページ移動しても維持されます。別の検索を始めると [既定の設定（英語）](../configuration.md#search-defaults)に戻ります。
メニューが表示されない場合は、端末で [`mash search --intent`（英語）](../search.md)を使えます。
[日本語など、英語以外のチャットを検索する](search-languages.md)

<span id="inspect-conversation-records"></span>

## 会話から保存された記憶を読む

左側の **memory** を開くか、その下にある種類を選びます。
上部から種類を切り替え、**find a statement** で検索し、状態、確認状況、記憶の出所で絞り込めます。
出所の項目では、このコンピューターの記憶か、グループに共有された記憶かを選べます。
**Apply filters** で検索し、**Next page** で続きの結果を表示します。

記憶を開くと、更新の履歴、根拠として引用されたメッセージ、関連する記憶を確認できます。
引用の下にある **open the message** は、チャットの該当メッセージを開きます。
チャットの **memory from this chat** には、そのチャットを根拠とした記憶が表示されます。
引用されたメッセージの下には **Saved as** と表示されます。

一覧には確認前や使用を終了した記憶も含まれます。使う前に、状態、有効期限、根拠に関する注意、矛盾の有無を確かめてください。
記憶を確認済みにしたり変更したりするには、エージェントに [記憶ツール（英語）](../records.md)を使うように頼みます。
共有された記憶の出所を開けない場合、リンク先にはエラーが表示されます。

<span id="keep-your-place"></span>

## 履歴の更新中も同じ場所を読み続ける

ダッシュボードは、このコンピューターの履歴と共有先に送られた履歴の更新を反映します。読んでいる位置は基本的に変わりません。

- **チャットや記憶の一覧**は、更新後数秒で新しい情報を表示します。概要、チャット横のセッション一覧、エージェント、コンピューター、プロジェクト、記憶の各ページも同様です。
- **開いているチャット**で会話の末尾を見ている間は、新しいメッセージが加わると表示も追従します。
  会話の途中を読んでいる場合は **N new messages** を選ぶと末尾へ移動します。
  すでに表示しているメッセージが更新された場合は **Show updated messages** で反映できます。
- **チャットや記憶の検索結果**は、次に検索を実行するまで条件や結果が維持されます。
  結果から会話を開き、ブラウザーの戻るボタンを押した場合も同じです。
- **開いている記憶**の表示内容を更新するには、**check for updates** を選びます。

ほかのコンピューターの更新を受け取るには、ダッシュボードと同じか新しいバージョンの共有サーバーが必要です。
古いサーバーを使っている場合や、ダッシュボードのタブを 16 個より多く開いている場合は、
左のメニュー下部の **reload chat list** や、チャットの更新ボタンで読み直せます。

ブラウザーとダッシュボードの間、またはダッシュボードと共有サーバーの間で接続が切れた場合は、自動的に再接続して新しい履歴を取得します。
新しいチャットを表示するには [履歴を読み込む（英語）](../synchronization.md#refresh-now)必要があります。ダッシュボードはインデックスが更新されると表示を更新します。

情報を取得できない場合は、エラーの内容と **Retry** が表示されます。
接続エラーの場合は通信状態と `mash dash` が動いていることを確認し、**Retry** を選んでください。

<span id="ask-mashy"></span>

## Mashy に質問する

[モデルを設定（英語）](../configuration.md#the-dashboard-assistant)すると、各ページの右下に Mash のマスコットが表示されます。
選ぶと Mashy と話せます。「先週の作業について教えて」「このチャットを要約して」のように、履歴について質問できます。

広い画面では、ウィンドウ上端をドラッグすると移動し、ダブルクリックで元の位置に戻ります。スマートフォンでは全画面で表示されます。

Mashy はチャットや記憶を検索して短く答えます。回答からダッシュボード内の情報に移動できます。

- チャットや記憶はボタンで開けます。根拠が特定のメッセージの場合は、そのメッセージまで移動します。
- 引用のカードには、誰がいつ書いたかが表示されます。自分の発言には色付きの縁が付きます。
- プロジェクト、エージェント、コンピューターを選ぶと対応するページを開けます。
- 一部の結果だけを使って答えた場合は、**See all** で同じ語句の検索結果を開けます。
- `mash index` などのコマンドは、**Copy** でコピーできます。

回答の下には追加の質問候補が表示されます。途中で止めるには停止ボタンを押します。
会話中の一部について聞くには、テキストを選択して **Ask Mashy** を押します。
選んだテキストは質問欄の上に留まり、外すまで各質問に添えられます。

検索の準備状況、最新チャットの日時、接続されたエージェント、各コンピューターの同期時刻も確認できます。
修復が必要な場合は、実行するコマンドを案内します。Mash 自体についての質問では、組み込まれたガイドを使い、リンク先はこのサイトで開けます。

時刻はブラウザーの設定に従います。「先週は何をした？」といった質問には、その期間にメッセージがあったチャットから回答します。
長い会話は分けて読むため、どの部分をもとに答えたかが表示されます。

Mashy は読み取り専用のツールで履歴やガイドを参照します。履歴の読み込みや削除、記憶の保存、コマンド実行、設定の変更は行いません。
Mashy との会話はブラウザーのタブを閉じるまで保持され、履歴には追加されません。
各質問で参照したテキストや選択した抜粋は、設定したモデルに送られます。モデルを設定した場合にだけ、Mashy が表示されます。

回答に問題がある場合は、`MASH_TRACE=1` を設定してダッシュボードを起動し、もう一度質問してください。
ログには、参照したツールと返した情報量、応答時間、使用したトークンの数、処理が終わった理由が記録されます。
質問、回答、履歴の本文は記録されません。

<span id="save-a-transcript"></span>

## 会話を保存する

チャットの **Export** メニューから **Export to Markdown** または **Export to HTML** を選ぶと、
ツールの出力も含めて会話全体を保存できます。
**Export to PDF** は印刷用の表示を開きます。ブラウザーの印刷画面で **Save as PDF** を選んでください。

内容が更新されているときは、読み込みが終わってから保存してください。保存した会話には機密情報が含まれる場合があります。

それぞれのチャットには `http://127.0.0.1:8790/#/chat/<chat id>` のようなアドレスがあります。
[プラグイン（英語）](../plugin.md)の `/mash:export` を使うと、指定したチャットをダッシュボードで開けます。

<span id="export-many-chats-at-once"></span>

## 複数のチャットをまとめて保存する

**chats** の **export chats** を開きます。エージェント、コンピューター、プロジェクト、期間で対象を絞り込めます。
ページをまたいで条件に合うすべてのチャットが対象です。保存しないチャットのチェックを外してください。
読むなら **Markdown**、スクリプトで処理するなら **JSON** を選び、**Export** を押します。
プロジェクトごとにフォルダーが分かれ、チャットごとのファイルが 1 つの `.zip` にまとまります。

ダウンロードが始まるまではページを開いたままにします。読み取れないチャットがあると保存は中止されます。
ファイルには会話全体とその中の機密情報が含まれる場合があります。添付ファイルは含まれません。

Mash に復元できるコピーが必要な場合は [持ち運べるバックアップ（英語）](../backup.md#make-a-portable-backup)を作成してください。
ほかのコンピューターのチャットをダッシュボードで見るには [履歴の共有（英語）](../shared-index.md)を使います。

<span id="open-it-from-your-phone-or-another-computer"></span>

## スマートフォンや別のコンピューターから開く

既定では、ダッシュボードは起動中のコンピューター上で開けます。
Linux または macOS で [Tailscale](https://tailscale.com) に接続している場合は、次のコマンドで同じ tailnet の別の機器からサインインして使えます。

```sh
mash dash remote
```

ダッシュボードが常駐サービス（Linux では systemd のユーザーサービス、macOS では LaunchAgent）として起動します。
tailnet 内の HTTPS アドレスと、サインイン用の 1 回限りのコードおよび QR コードが表示されます。

```json
{
  "dashboard": "https://laptop.your-tailnet.ts.net:8790/",
  "service": "mash-dash.service",
  "code": "K7M-2QX",
  "code_minutes": 10
}
```

スマートフォンを Tailscale に接続し、QR コードを読み取るか、アドレスを開いてコードを入力してください。
そのブラウザーのサインインは 30 日間有効です。

| 操作 | コマンド |
| --- | --- |
| 別の機器でサインインする | `mash dash remote --code` |
| QR コードを表示し直す | `mash dash remote --qr` |
| 別のポートを使う | `mash dash remote --port 8791`（各コマンドに指定） |
| ローカル履歴のないコンピューターで動かす | `mash dash remote --shared-only` |
| Tailscale のない機器からアクセスする | `mash dash remote --public --port 8443` |
| 停止する | `mash dash remote --remove` |

コードは発行から 10 分以内に 1 回使えます。QR コードには長期間有効なトークンがアドレスの `#` の後ろに含まれます。
この部分はサーバーに送られず、ダッシュボードがサインイン後すぐにアドレスから取り除きます。QR コードの画像はパスワードと同じように扱ってください。

ダッシュボードは、起動したコンピューターの履歴と、アクセスできる共有履歴を検索します。
`mash init --join` を使った場合は、ダッシュボードが `~/.mash/node.env` から接続トークンを読み取れます。
v0.1.1-alpha では、トークンが有効でもローカル専用と表示されることがあるため、別のコンピューターのチャットを開いて確認してください。
[複数のコンピューターの履歴を検索する（英語）](../shared-index.md#search)

手動で共有を設定した場合は、`mash dash remote` を実行するシェルで接続トークンの環境変数を設定します。
Mash はサービス用にその値を `~/.mash/dashboard.env` に保存します。このファイルを読めるのは自分だけです。
macOS の場合、LaunchAgent は環境変数を `~/Library/LaunchAgents/dev.mash.dash.plist` に保存し、出力を `~/.mash/dashboard.log` に書きます。

共有インデックスへの接続とトークンの設定があるコンピューターは、`mash dash remote --shared-only` でダッシュボードを起動できます。
そのコンピューターに履歴がなくても、共有インデックスのチャット、検索、記憶を使えます。

`--public` は [Tailscale Funnel](https://tailscale.com/kb/1223/funnel) を使ってアドレスをインターネットに公開します。
自分の tailnet に入っていない機器からも開けます。対象のコンピューターで Funnel を許可する必要があり、公開できるポートは 443、8443、10000 です。
サインイン画面は誰でも開けるようになり、全チャットの履歴を保護するのはトークンと一時コードだけです。
1 分に 10 回間違えると、自分も含めてすべての人のサインインが一時停止します。通常は tailnet 内での既定のアクセスを使ってください。

<span id="set-it-up-by-hand"></span>

### 手動で設定する

Windows を使う場合や、Caddy などの HTTPS リバースプロキシを使う場合は、次の手順で設定できます。

1. 32 文字以上のトークンを用意し、`MASH_DASH_TOKEN` などの環境変数に入れます。
2. ダッシュボード用の HTTPS アドレスを設定します。Tailscale の場合は `tailscale serve --bg 8790` を使えます。
3. そのホスト名とトークンの環境変数名を指定して、ダッシュボードを起動します。

   ```sh
   mash dash --allow-host laptop.your-tailnet.ts.net --access-token-env MASH_DASH_TOKEN
   ```

`--allow-host` にはブラウザーからアクセスするホスト名を指定し、アドレスにポートが含まれる場合はそのポートも指定します。
ホスト名が複数ある場合は、名前ごとにフラグを指定してください。トークンを変更すると、すべてのブラウザーでサインアウトされます。

<span id="keep-access-private"></span>

## アクセスを制限する

`--access-token-env` を指定すると、チャット履歴のすべてのページを読むにはサインインが必要です。
1 分間に誤ったトークンが 10 回送られると、その分が終わるまでサインインできなくなります。

トークンを指定していない場合は、自分のコンピューターからだけ開ける既定のアドレスで使ってください。
`mash dash --listen` で別のアドレスを指定すると、そこに接続できる人は誰でも履歴を読めるため、起動時に警告が表示されます。
`--allow-host` を指定する場合はトークンが必要です。

自分の機器の間で使う場合は、プライベートネットワークを使ってください。
アドレスをインターネットに公開するとトークンだけが履歴を保護します。
Cloudflare Tunnel など、HTTPS を終端するサービスを利用すると、そのサービスは通信の内容を読み取れます。
