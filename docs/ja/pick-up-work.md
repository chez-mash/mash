# 作業を再開する

前回のチャットを開き、次に取りかかれる作業を見つけましょう。

<span id="follow-a-sample-handoff"></span>

## 作業の引き継ぎをデモで試す

1. [デモで保存済みのログイン方針を開く](https://getmash.io/demo/#/record/record-sign-in-tokens?node=laptop)。
2. **open the message** を選んで、元の Claude Code の会話を読みます。
   残っている作業は、モバイルアプリのリフレッシュトークンを端末のキーチェーンに保存することです。
3. **See the Codex follow-up** を選び、後のサンプルチャットで Codex がその作業をどう引き継いだかを確認します。

<span id="find-the-next-step-in-your-chats"></span>

## チャットから次にやることを見つける

1. ダッシュボードで **chats** を開き、作業中に使ったファイル名、エラーメッセージ、フレーズなどを検索します。
   複数のプロジェクトに似たチャットがある場合は、プロジェクトで絞り込みます。
2. 検索結果からチャットを開き、最後の数件のメッセージを読みます。終わったこと、合意した方針、
   残りのテストや作業を確認します。関係するツール出力があれば開いて、実際に何が行われたかを確認します。
3. 自分で次の作業に着手するか、新しいエージェントセッションに短い要約を渡します。
   要約には、目的、引き続き適用される決定、残っている作業を含めます。

目的のチャットを探すには、[ダッシュボードでの検索方法](dashboard.md#find-and-read-a-chat)と
[チャットが検索結果に出ないときの確認手順](troubleshooting.md#search-returns-no-results)をご覧ください。

<span id="reopen-the-original-session"></span>

## 元のセッションを開き直す

Codex または Claude Code の会話を開き、**Copy session ID** を選びます。
元のセッションが保存されているコンピューターで、対象プロジェクトのフォルダーを端末で開きます。
使っているエージェントに対応するコマンドの `SESSION_ID` に、コピーした ID を指定してください。

```sh
codex resume SESSION_ID
claude --resume SESSION_ID
```

ID で開けない場合は、エージェントのセッション選択画面でタイトルからチャットを探すか、
新しいセッションを開いて要約を渡してください。

<span id="ask-an-agent-for-a-recap"></span>

## エージェントに前回の作業をまとめてもらう

Mash プラグインと検索ツールを設定したら、続けたいプロジェクトで新しいセッションを始めます。
Claude Code では `/mash:resume` を実行します。Codex または Copilot では
「Mash の resume スキルを使って、このプロジェクトで前回どこまで作業したか教えて」と頼みます。
[エージェントでの Mash のセットアップ（英語）](../plugin.md#finish-setup-in-the-agent)

このスキルは、インデックスの更新を試みたあと、引き継ぎメモがあるか確認し、プロジェクトの最近のチャットを読みます。
前回やったこと、残っている作業、次にやることをまとめます。
決定の経緯を確認したい場合は、その根拠となった元のメッセージを見せるよう頼んでください。

<span id="leave-a-handoff-for-the-next-session"></span>

## 次のセッションに引き継ぎメモを残す

1. セッションを終える前に、Claude Code で `/mash:handoff` を実行するか、
   エージェントに Mash の `handoff` スキルを使うよう頼みます。
   スキルは現在のチャットに短い引き継ぎメモを書きます。対象のファイルやブランチ、決まったこと、
   残っている作業、次にやることが書かれているか確認します。
2. エージェントがメモを書き終えたら、チャットを保存したコンピューターで `mash index` を実行します。
   同じコンピューターなら、作業を再開するときに resume スキルでインデックスを更新することもできます。
3. 次のセッションで同じプロジェクトを開き、エージェントに `resume` を使うよう頼みます。
   ダッシュボードで `"Mash handoff"` を検索し、自分でメモを読むこともできます。

別のコンピューターに移る場合は、先に共有を設定し、メモを書いたコンピューターでインデックスを更新します。
これで、メモを含むチャットを共有インデックスに送れます。
手動で引き継ぐなら、新しいセッションにメモをコピーします。次のエージェントに読ませたい内容だけを共有してください。
[複数のコンピューターの履歴を検索する（英語）](../shared-index.md) ·
[エージェントが読める履歴](privacy.md#when-history-can-leave-your-machine)
